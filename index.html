At work2021 to now

I work on a bulk payments platform at a Big-5 Canadian bank: Kafka event flows, database and API validation, and a regression cycle that is now almost entirely automated. Nightly regression, smoke suites and release gates run in Jenkins.

Three tools came out of that work. I built each of them with AI coding tools, in days, and my team uses them every release.

Test cases from a user story

Paste a user story or a requirements page. It returns structured test cases, as a workbook for review or as a file ready to upload into test management.

One-click payment trace

Follows a single payment from the payment network, through the database, to its Kafka event. It then writes the tracking record and a step-by-step evidence document with screenshots. It runs on a laptop or from Jenkins.

Payment test-data generator

Generates valid bulk payment test files across transaction types, with one configuration per environment, so the same scenario runs everywhere.

Described at a high level on purpose. The client's systems, code and data stay with the client.

SwiftGen AI

An iOS app generator. Built alone.

You describe an app in one sentence. It plans the app, writes native SwiftUI, compiles it, repairs what breaks, launches it in the iOS Simulator and streams it to your browser.

The part I spent the most time on is everything that stops a model's output from reaching a user unchecked: about 970 rules that run before any build, a repair loop that tries three times, and a final step that launches the app, takes a screenshot and reads the crash log.

How I check AI's work

  • Fix the system, not the output. I do not hand-patch what a model wrote. I fix the prompt or the check that let it through, then test again.
  • A passing build proves nothing. Launch it, tap it, take a screenshot, read the crash log.
  • Measure first, then claim. Every number on this page comes from logs or live data, with its date.
  • Check against something the AI did not write. Official tables, the specification, a second system.
